What’s New In This Release Major Changes to Core OS Sched

  • #20596 sched: Add options for the argument limits of a new task
  • #20391 sched: Fix deadlock cycle collection.
  • #20420 sched/clock: keep the seqlock sequence in uint32_t
  • #20640 sched/signal: Run a synchronous signal handler out of the critical section
  • #20424 sched/signal: validate a sigevent’s signal and target thread
  • #20543 sched/task: Do not log a missing or unloadable program as an exec error
  • #20651 sched/task: make task reparenting transactional
  • #20650 sched/task: record status for the terminated child
  • #20438 sched/timer: a timer handle works only in its own proces

MM

  • #20600 mm/mm_gran: Count granules in 32 bits.
  • #20629 mm/mm_gran: Do not skip free granules below a used bit outside the range
  • #20638 mm/umm_heap: Do not set errno in the kernel copy of the user heap

libc

  • #20489 libs/libc: Generate the system symbol tables in the CMake build.
  • #20550 libs/libc/arm64: Do not dereference a NULL symbol in up_reloateadd()
  • #20601 libs/libc/elf: Read the symbol and string tables at once to find a symbol
  • #20555 libs/libc/elf: Read the symbol table at once for RELA relocations.
  • #20597 libs/libc/elf: Return ENOEXEC for a file shorter than an ELF header
  • #20693 libs/libc/netdb: separate h_errno from EAI error codes
  • #20560 libs/libc/time: Set tm_zone to “UTC” in gmtime_r()
  • #20634 libs/libc/stdlib: Raise SIGABRT in abort()
  • #20633 libs/libc/stdio: Flush a line buffered stream at a newline in fwrite()
  • #20595 libs/libc/stdio: Close the descriptor in fclose() of a standard stream
  • #20440 libs/libc/termios: Fix the ttyname_r buffer overflow with long tty paths.
  • #20602 libs/libc/unistd: Return ARG_MAX from sysconf(_SC_ARG_MAX)
  • #20632 libs/libm: Compute frexp() and ldexp() exactly.
  • #20682 libs/libm: support 128-bit quad-precision and universal fallback in truncl

tools

  • #20663 tools/flash_writer.py: Replace removed telnetlib for Python3.13+

various

  • #20507 audio: Fix the build with CONFIG_AUDIO_MULTI_SESSION
  • #20409 binfmt: copy argv and file actions once, bounded
  • #20556 binfmt: Search PATH only for a file name without a slash.
  • #20468 binfmt: Update the TLS pid when exec() swaps the pids.
  • #20635 include: Fix sys/wait.h without stdbool.h, and add MAXPATHLEN and in6addr_loopback
  • #20594 include/elf.h: Define the ELF32 and ELF64 types on all targets
  • #20645 include/nuttx/sdio: guard callbackenable under HPWORK support
  • #20646 include/nuttx/vt100: fix macro syntax errors and add cursor movement
  • #20529 include/sys/types.h: Define wchar_t before including
  • #20538 openamp: Do not trust buffer and header lengths written by the remote. Major Changes to the Build System Improvements
  • #20610 cmake: deduplicate NUTTX_EXTRA_FLAGS in linking stage
